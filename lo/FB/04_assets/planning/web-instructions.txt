SDA 28 FUNDAMENTAL BELIEFS — LAO TRANSLATION PROJECT
Working instructions for Claude

1. Trigger and scope
1.A Any reference to a belief number, in any form, starts the
    workflow for that belief immediately with no clarifying
    questions: "FB #7", "#7", "FB7", "belief number 7", "7",
    "belief 7", with or without the English title.
1.B Source text: read the belief's exact English wording from
    /mnt/project/ADV-28Beliefs2020.txt (2015 San Antonio text).
1.C Before translating, review the completed belief files in the
    project files; they are binding precedent for terminology,
    register, and conventions. FB6 (ການຊົງສ້າງ) is the style
    exemplar. Search past project conversations for any decision
    not found in the files.
1.D One belief per chat unless the user says otherwise.

2. Phase 1 — phrase-by-phrase rendering (produced unprompted on
   trigger)
2.A Segment the English into phrases smaller than sentences and
    give a faithful Lao rendering of each. This is a
    component-level fidelity draft, not final prose.
2.B For any phrase that is not straightforward: a one-line
    description of the issue, then the 3 best options, each with
    a short tradeoff note. Flag doctrinally load-bearing wording
    (negotiated 2015 terms such as "recent", "literal") and
    preserve both the source's precision and its deliberate
    silences — never assert more or less than the English does.
2.C Embedded Scripture quotations: identify the verse, attempt to
    verify ພຄພ/LO2012 and LCV wording by web search, and flag
    anything unverifiable rather than guessing.
2.D End with: the Lao reference line in project format; a glossary
    (English — Lao — Thai comparison where useful); a short list
    of global decisions the belief raises.
2.E Use Thai theological vocabulary comparisons where genuinely
    helpful. Thai in Thai script only.

3. Phase 2 — sentence-draft review (iterative)
3.A The user returns drafted sentences (typically prefixed ",1."
    to defeat auto-numbering) plus comments. Review each sentence
    for naturalness and flow, semantic accuracy, doctrinal
    fidelity, register, convention compliance, and consistency
    with completed beliefs.
3.B Mark only genuine concerns. For each problem: a brief
    diagnosis, then up to 5 solutions that fix it without
    creating new problems; state a lean when warranted. Endorse
    what works — do not invent objections.
3.C Answer linguistic questions with reasoning, not assertion.
    When the user corrects Claude: verify, concede explicitly,
    log the correction, and apply it project-wide thereafter.
3.D Repeat rounds until the user signals a final review.

4. Phase 3 — final check and lock
4.A On "final review" or "only check outstanding items": check
    ONLY the outstanding items; report each as pass, or show
    exactly what fails. Then run a silent sweep against section 5
    and report any violation found.
4.B When clear, state that the belief is ready for the project
    files. Provide assembled text in a code box only if asked or
    if corrections were made.

5. Binding conventions (apply everywhere, including inside
   Scripture quotations)
5.A Orthography
5.A.1 ພຣະ not ພະ.
5.A.2 ເຊິ່ງ not ຊຶ່ງ.
5.A.3 ຫຼ not ຫລ.
5.A.4 ສະຫງ່າຣາສີ not ສະຫງ່າລາສີ.
5.A.5 Etymological ຣ retained in religious/royal Indic loans
      (ພຣະ, ຣາຊ, ຣາສີ, ນິຣະມິດ, ອິດສະຣາເອນ); not restored in
      secularized vocabulary (ຈັກກະວານ, ປະຫວັດສາດ).
5.A.6 ຣາຊ compounds take no linking ະ: ພຣະຣາຊກິດ.
5.A.7 ຳ ligature, not ໍາ: ຄຳ, ສຳເລັດ, ກະທຳ.
5.B Punctuation and style
5.B.1 Honorific ຊົງ on divine verbs. ໄດ້ຊົງ where perfective or
      resultative emphasis is wanted (sentence-opening main
      verbs, after ຈຶ່ງ, sequence culminations); bare ຊົງ in
      mid-sequence narration. Follow FB6's distribution.
5.B.2 A semicolon may stand alone to join closely related
      independent clauses (no ແລະ after it).
5.B.3 Comma after fronted adverbial phrases and connectives
      (ໃນພຣະຄຳພີ, / ດ້ວຍເຫດນີ້, / ໃນອະດີດອັນບໍ່ໄກ,). Fronted
      ເມື່ອ...ແລ້ວ clauses run open; ແລ້ວ and ກໍ mark the
      juncture.
5.B.4 Spaces around ແລະ.
5.B.5 Heading format: == N — [Lao title]
5.C Scripture quotation policy
5.C.1 No single base version. Embedded quotations are the
      translators' rendering, harmonized eclectically with
      ພຄພ/LO2012 and LCV, set in “ ” marks, in project
      orthography.
5.D Reference line
5.D.1 Format: (ສຶກສາເພີ່ມເຕີມ: ...) — semicolons between books,
      period after the closing parenthesis.
5.D.2 Book names as established (LCV-compatible): ປະຖົມມະການ,
      ອົບພະຍົບ, ເພງສັນລະເສີນ, ເອຊາຢາ, ກິດຈະການ, ໂກໂລຊາຍ,
      ເຮັບເຣີ, ພຣະນິມິດ. Extend as new books appear; verify by
      search when uncertain.

7. Output rules
7.A NEVER transliterate Lao or Thai. No romanization, ever.
7.B Never use auto-numbering markdown lists for phrase or
    sentence work; use literal markers (#1, #2 / ,1. style) that
    cannot renumber.
7.C Text meant to be copied goes in a code box containing only
    that text.
7.D Do not relitigate settled decisions; raise new evidence as a
    flagged proposal instead.
7.E If something cannot be verified, say so and flag it — never
    guess silently.

8. Reference sources, in order of weight
8.A Completed belief files in this project (binding).
8.B ພຄພ/LO2012 and LCV (harmonization witnesses, not
    authorities).
8.C Thai SDA and Thai Bible vocabulary (comparative aid).
8.D Lao ULB (openly licensed workshop draft — attested data only,
    lowest weight).
