# PP side quests — the queue

Work on th/PP that is agreed but not scheduled, in the order it will be done. When the translator asks how many PP side quests are open and in what order, this file is the answer and no agent answers from memory. An issue he defers rather than decides is added here in the same reply that defers it, and an entry is deleted when its work is finished, not marked done, because a finished quest is in the commit history. Each entry says what the job is, where its detail lives, and roughly how big it is. The file follows th/SC/04_assets/planning/SIDEQUESTS.md.

## 1. PP book rules, to move into a PP procedure file when one exists

PP has no procedure file yet. These rulings apply to PP only, so they were taken out of the shared th/assets/translation_profile/thai-profile.txt on 26 September 2026 and wait here.

1.A. A quotation in TH1971, PP's default version, from a verse inside the chapter's based-on reference carries no printed citation, only a hidden comment such as /*ปฐมกาล 8:21–22 TH1971*/; a quotation in any other version is labelled.
1.B. A based-on line writes บทที่ only when every part is a whole chapter, with a space after the book name; ranges take an unspaced en dash; two chapters take และ; other lists take "; ".
